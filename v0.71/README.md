# CIW 키오스크 인터랙션 테스트 v0.71

2026-10-15 기준 독립 테스트 버전이다. 앞의 5개 화면은 v0.7의 디자인을 재사용하고, 카드결제·결제완료는 같은 Figma 페이지의 최신 디자인을 반영했다. [index.html](index.html)을 브라우저에서 직접 열어 실행한다. HTML과 assets 폴더를 함께 보관한다.

최신 디자인 기준은 `화면설계서 (KIOSK)_v0.3_Design` 페이지의 [카드결제 920:4089](https://www.figma.com/design/pTygpdbWWcya2gW84a6tma/?node-id=920-4089)와 [결제완료 840:10522](https://www.figma.com/design/pTygpdbWWcya2gW84a6tma/?node-id=840-10522)이다. 동일한 이름의 이전 카드결제 프레임 817:1185는 사용하지 않는다. 카드 리더기 자산 영역은 원본의 흰색 빈 영역을 유지하며 이 영역을 누르면 승인을 체험할 수 있다. 결제완료의 차량 진입 안내는 Figma에서 제공된 PNG 원본을 사용한다. 영수증과 하단 버튼은 디자인을 표시하되 비활성화하여 완료 화면에서 멈춘다. 설계서 설명용 빨간 번호 표식은 표시하지 않는다.

## 체험 순서

1. SUV 또는 세단을 선택한다.
2. 세차 코스를 선택한다.
3. 코스 선택 화면 위에 뜨는 할인권 팝업에서 사용 또는 사용 안함을 선택한다.
4. 사용을 선택했다면 스캔 안내를 누른다. 인식 확인 후 2,000원이 차감된다.
5. 결제수단 화면에서 카드 결제를 선택한다. 이 화면의 주유 할인권 버튼에서도 스캔 화면으로 진입할 수 있다.
6. 카드 리더기 영역을 누르면 승인 표시 후 결제가 완료된다.
7. 결제완료 화면에서 종료한다. 왼쪽 처음부터 다시 테스트 버튼으로 반복한다.

## 화면 범위

| 순서 | 화면 ID | 화면 |
|---|---|---|
| 1 | KIO-INT-001 | 차종 선택 |
| 2 | KIO-CRS-001 | 코스 선택 |
| 3 | KIO-DSC-001 | 주유 세차 할인권 사용 여부 |
| 4 | KIO-DSC-002 | 주유 세차 할인권 스캔 |
| 5 | KIO-PAY-001 | 결제수단 선택 |
| 6 | KIO-PAY-101 | 카드결제 |
| 7 | KIO-CMP-001 | 결제완료 |

할인을 건너뛰면 DSC-002를 거치지 않는다. 결제수단 화면에서 할인을 적용하면 다시 PAY-001로 돌아온다. 성공 안내는 PAY-001 위의 메시지이며 별도 화면으로 이동하지 않는다.

앱결제·상품권·쿠폰·QR 직접 사용·코스 상세·관리자·외부 결제 팝업·영수증은 이번 테스트에서 제외한다. 해당 버튼은 비활성화하거나 숨긴다. 주소의 화면 값과 화면 이동도 위 7개로 제한한다. 무조작 타임아웃은 멈추고 화면의 30초 표시는 정지 상태로 유지한다.

## 인터랙션 기준

- 누를 때 즉시 살짝 축소하고, 손을 떼면 부드럽게 복원한다.
- 화면은 짧게 물러난 뒤 다음 내용이 가볍게 들어온다. 뒤로 이동할 때는 방향을 반대로 한다.
- 차량·코스 항목은 짧은 시간 차를 두고 나타난다.
- 인트로의 SUV·SEDAN 버튼은 대기 중 정지한다. 누름 반응과 최초 진입 효과만 적용한다.
- 할인 팝업은 배경을 어둡게 하고 작은 크기에서 자연스럽게 자리 잡는다. 닫힐 때도 짧게 축소된다.
- 코스를 선택하면 같은 코스 화면을 배경으로 유지한 채 할인 팝업을 띄운다. 팝업 뒤의 코스 버튼은 조작할 수 없다. 사용 안함은 결제수단 선택으로, 사용은 할인권 스캔으로 이어진다.
- 스캔 확인은 약 0.65초, 카드 승인 표시는 약 1초 후 다음 화면으로 이어진다. 반복 누름으로 중복 처리하지 않는다.
- 할인 적용 시 최종 금액을 부드럽게 낮추고, 화면 조작을 막지 않는 안내를 띄운다.
- 완료 시 진입 안내 상자가 부드럽게 나타난 후 화면을 유지한다.
- 팝업의 키보드 포커스를 내부에 유지한다. Esc는 사용 안함으로 처리한다. 카드 리더기는 Enter·Space로도 체험할 수 있다.
- 동작 줄이기 설정에서는 장식 애니메이션을 생략한다. 승인 처리·화면 이동·금액 계산은 동일하게 동작한다.
- 처리 중 처음부터 다시 테스트를 누르면 이전 동작을 취소해 뒤늦은 화면 이동을 방지한다.

## 다음 비교 버전 만들기

v0.71은 부드러운 복원과 순차 진입을 기준안으로 사용한다. 다음 버전은 동일 디자인·플로우·처리 시간을 유지하고 화면 전환 속도 또는 복원 강도 한 가지만 바꿔 비교하면 된다. 현재 버전에는 효과 선택 메뉴를 넣지 않았다.
