# CIW 키오스크 프로토타입 v0.7

Figma `(작업용) v0.7`의 세로형 기본 화면을 기준으로 한다. 기본 IA 42개와 분리된 PAY-002, 결제완료 흐름용 CMP-001을 포함해 44개 화면을 제공한다.

- 높은 화면의 결제·결제완료 배치는 사용자 지정 [(sample) PAY-001](https://www.figma.com/design/rpAk7c9wxxP5rAcrgPLy3l?node-id=910-12184) 및 [(sample) CMP-001](https://www.figma.com/design/rpAk7c9wxxP5rAcrgPLy3l?node-id=887-13979)을 따른다. 결제 영역 상단 여백 80px, 기능 버튼 1100px, 상태 정보 1204px, 하단 광고 640px로 배치한다.

- 최신 인트로: 세로형 [KIO-INT-001 · 589:12484](https://www.figma.com/design/KO0UT5heAXBbCxCTFSnQ6U?node-id=589-12484), 가로형 [KIO-INT-001-W · 887:13589](https://www.figma.com/design/rpAk7c9wxxP5rAcrgPLy3l?node-id=887-13589). 기능 번호 주석은 제외하고 원본 자산·안내 문구·정보 영역을 반영했다. 세로형 차종 선택과 QR 인식, 가로형 화면 터치 시작·숨김 관리자 진입을 제공한다.

## 최종 디자인 업데이트 — 2026-10-26

1차 19개에 이어 2차 7개 화면을 갱신했다. v1·v2는 상태별 시안으로 적용했다. 현재 보류: AUT-001~005, 중복·오표기 CMP-002·PAY-302·CMP-005·ADM-001·COM-001. [반영 화면·대지 목록](DESIGN_UPDATE_2026-10-26.md)을 참고한다. 기존 기능과 이동은 유지한다.

- 할인은 적용 후 PAY-001로 복귀한다. 상품권·쿠폰은 적용 후 잔액이 0원이면 결제 완료로 바로 이동하고, 잔액이 남으면 PAY-001로 복귀해 ‘적용됨’을 표시한다. 주유 할인권과 할인 쿠폰은 중복 사용하지 않는다.
- PAY-001의 미적용 상태는 ‘사용 안함’, 적용 후는 ‘다음’으로 진행한다. 상품권·쿠폰으로 전액 결제되면 다음 버튼을 거치지 않고 바로 완료한다.
- PAY-002의 이전 버튼은 금액·적용 상태를 유지한 채 PAY-001로 돌아간다. 카드 선택은 PAY-101로 바로 이동한다.
- 카드 안내 그림을 누르거나 4.2초가 지나면 결제 완료를 시뮬레이션한다. 기존 외부 결제 팝업 화면은 화면 목록에서 별도로 볼 수 있다.
- 로컬 이미지·폰트를 사용하며 파일을 직접 열 수 있다. 실제 결제 장치 연동은 시뮬레이션이다.

- 배치·색상·문구·원본 자산은 지정 대지를 따른다. 빨간 기능 번호는 설계 주석이므로 이용 화면에 표시하지 않는다. 코스 선택 대지 내부에 없는 하단 버튼은 추가하지 않으며 화면 높이는 기존 검토 패널에서도 변경할 수 있다.
- 코스명·금액·할인 내역·최종 결제금액은 기존 거래 상태를 사용한다. 샘플 금액을 고정하지 않는다.
- 코스 선택 후 할인 팝업은 결제수단 화면 위에 표시한다. 결제수단 화면의 주유 할인 버튼에서는 스캔 화면으로 바로 이동한다. 주유 할인권과 할인 쿠폰은 중복 적용하지 않는다.
- 기본 화면은 광고가 위에, 높은 화면은 광고가 아래에 위치한다. 높이를 바꿔도 거래 상태를 유지한다.
- 화면 진입 280ms, 팝업 진입 320ms, 버튼 누름 150ms의 부드러운 반응을 적용한다. 30초 카운트와 스캔 안내 모션은 Figma 타임라인을 사용한다. 동작 줄이기 설정에서는 장식 모션을 생략하며 카운트 숫자는 계속 갱신한다.
- 할인 팝업은 키보드 포커스를 내부에 유지하고 Esc로 사용하지 않고 닫을 수 있다. 전체화면 모아보기에서는 진입·스캔 모션을 생략해 정지 화면으로 확인한다.
- 다른 화면의 디자인과 실제 장치·결제 연동은 이번 변경 범위에 포함하지 않는다.
