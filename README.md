# CIW 키오스크 HTML v0.7

- UI 기준: [Figma `(작업용) v0.7`](https://www.figma.com/design/rpAk7c9wxxP5rAcrgPLy3l/Eojin_CIW_KIOSK--v0.6-?node-id=602-7859)
- 범위: 세로형 기본 화면. W·v1·v2 및 인트라넷 화면은 HTML 대상에서 제외.
- 실행: 프로토타입 HTML 또는 전체화면 HTML을 브라우저에서 연다. 서버·설치가 필요하지 않다.
- 화면 수: 기본 IA 42개 + 결제완료 흐름용 CMP-001 1개 = 43개. Figma 기본 프레임 43개에는 CMP-002 중복이 있고 CMP-001은 미배치되어 있어 기존 완료 흐름에만 CMP-001을 유지했다.

## 검토용 조건

- 코스 가격·회원·기기 정보는 예시다. 코스 선택 프레임은 가격이 모두 11,000원으로 표기되어 있으나 코스 설명 이미지 및 기존 결제 예시는 11,000/12,000/13,000/15,000원이다. 결제 계산과 코스 설명의 일관성을 위해 기존 예시 가격을 유지했다.
- 관리자 로그인 예시 비밀번호는 Figma 정책의 `1234`이다. 실제 장치·결제·바코드·PLC 연동은 기존과 같이 시뮬레이션한다.
- 관리자 설정 저장 시 변경 내용은 현재 브라우저 실행 중에 반영된다.
- 영수증 발급 성공 후 해당 결제의 발급 버튼을 숨긴다. 취소·실패 시에는 유지하고 새 결제에서 다시 표시한다.
- 네트워크 오류 화면의 원본 아이콘 3개는 추가 다운로드 허용이 거절되어 기존 ‘캐릭터 활용’ 자리 표시를 유지했다.
- Figma의 빨간 기능 설명 번호는 제품 UI에서 제외했다.
- 코스 설명 프레임은 Figma에 이미지 한 장으로 들어 있다. 이를 화면 배치 참고로만 사용하고, 실제 HTML은 코스 정보와 닫기 버튼으로 구성했다.
