`미리보기.cmd`를 더블클릭하면 브라우저에서 실행됩니다. Python이 설치된 Windows 환경을 사용합니다. 실행 창을 닫으면 미리보기가 종료됩니다.

`index.html`을 직접 열어도 화면과 탐색은 동작하지만, 브라우저의 로컬 파일 보안 정책으로 SVG 마스크가 적용된 일부 캐릭터가 숨겨질 수 있습니다. 디자인 확인은 `미리보기.cmd`로 실행해 주세요.

- 세차 시작 → 코스 선택 → 할인권 사용 여부 → 결제수단 → 카드 승인 시뮬레이션 → 완료 → 영수증 입력을 체험할 수 있습니다.
