# v0.72 인터랙션 테스트 수정 규칙

- v0.7·v0.71은 수정하지 않는다. 이 버전은 v0.71을 복사한 독립 실행 버전이다.
- v0.72의 인터랙션은 참고 D안의 오른쪽→왼쪽 채움을 우리 메인 레드(#d10a2c)와 흰 글자, 은은한 광택으로 맞춘 방식이다. 인트로의 대기 중 떠있는 효과와 큰 세로 펼침은 넣지 않는다. 할인 팝업은 코스 화면 위에서 열린다.
- 허용 화면은 INT-001, CRS-001, DSC-001, DSC-002, PAY-001, PAY-101, CMP-001의 7개뿐이다. 목록은 assets/screen-catalog.js가 관리한다.
- 팝업 버튼에는 색칠 효과를 적용하지 않는다. 차량·코스·결제수단 버튼의 채움 효과는 유지한다.
- 앞의 5개 화면 디자인과 원본 이미지는 v0.7을 재사용한다. 카드결제(920:4089)·결제완료(840:10522)는 README에 명시된 Figma 최신 디자인을 사용한다. 인터랙션과 이 두 화면 스타일은 assets/init.js와 assets/interactions.css에서 관리한다.
- 외부 결제 팝업, 앱결제, 상품권, 쿠폰, QR 직접 사용, 관리자, 영수증, 공통 타임아웃 화면으로 이동하지 않는다.
- 스캔·카드 승인·할인 금액은 시뮬레이션이다. 선택한 코스와 할인 금액은 실제 상태를 따라 계산한다.
- 결제완료에서 플로우를 멈춘다. 초기화는 테스트 패널에서 명시적으로 실행한다.
- 빠른 연속 누름, 진행 중 재시작, 키보드, 동작 줄이기, 기본·높은 화면을 확인한다.
- 새 패키지·빌드 도구를 추가하지 않는다. HTML을 직접 열 수 있는 구조를 유지한다.
- QA·스크린샷·임시 도구는 이 배포 폴더에 넣지 않는다.
